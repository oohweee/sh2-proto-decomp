# Characters and enemies

Maps the prototype's internal character codes to the public names of Silent Hill 2.

How to read this:
- **Code**: the three-letter name the original code uses (in function names such as
  `shCharacterSetEnemySCULow` and `enSCUInitData`, and in the enemy kind enum `EnKIND_*`).
- **Kind**: the character kind (model ID) passed to `shCharacterCreate`. The kind-to-handler switch
  is `shCharacterSetHandler` (src/Chacter/m3_sc.c). Enemy kinds map to `EnKIND_*` in `enTransID`
  (src/Enemy/en_common.c; the enum is at the top of that file).
- **Assets**: file-index symbols (`data_chr_<dir>_<name>_<ext>`, declared in include/sh2/variables.h).
  The repo has only these symbols. It doesn't record the original path strings.
- **Confidence**:
  - **verified**: code on the disc ties the code name to the character: a stage event that loads
    the model, the demo player's cast table, or a unique behaviour. The public name then follows
    from well-known game facts.
  - **by name**: the evidence is the developers' own names (event programs, demo file names) from
    stages whose code isn't on the disc. The names are original, but no code on the disc confirms
    what they name. The event-program names of those stages are listed in
    [missing-overlays.md](missing-overlays.md).
  - **suspected**: a name reading or a plausible match, with the reason given.

Main tables used below:
- `enemy_list` (kind → model/anim/shadow) and `item_list` (object kinds 0x3xx-0x7xx → model),
  src/Event/chara_data_load.c.
- `anim_info` (src/Event/demoview.c): the demo player's cast table. A demo script (`.dds`) names
  each of its characters by a string such as `hhh_mar_pos`; `DramaDemoInit` looks the string up
  in `anim_info` to get the character kind, and `DramaDemoAnimationStart` sends each kind to its
  handler (0x106 to `shCharacterHumanDMARAnimeSet`, ...). So a cast name ties a model name to a
  kind.
- Per-kind animation frame size: `shCharacterAnimeOneFrameSize` (src/Chacter/m3_sc.c).

## Model-name variants of James and Maria

`lll`, `hll`, `hhl` and `hhh` are model variants (plus `r` for mirror copies and `_notex` for
untextured cutscene copies). The code shows which kind uses which: the player uses lll or hll, drama
James uses hhl (0x102) or hhh (0x103), gameplay Maria uses lll (0x105) and drama Maria hhh (0x106).
What the letters stand for is unknown.
